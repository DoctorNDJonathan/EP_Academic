Exam Proctor: Quick Checklist

One page for every class test · Dashboard: exam-proctor-rhbo.onrender.com/dashboard · Help: nikhildj@xime.org
1 to 2 weeks before

Plan

  • Slot booked with Nikhil (max 40 students online at once, all tests together)
  • Allowed sites listed, including sign-in pages (Handbook, Appendix A)
  • Google Form link entered without /viewform
  • "Flag leaving Chrome" off only if the test needs a desktop app
  • Test created: COURSE-SECTION-TEST, times, new PIN, roster pasted
  • Every test link checked in Test a link: all say Allowed
1 week before

Prepare students

  • Student Guide PDF emailed with the test code, date and allowed sites
  • Alternative offered to students who can't use Chrome or don't consent
  • Practice test created (10 minutes, same allowed sites)
  • Practice join run in class or online; problems fixed
Day before

Remind

  • Reminder sent: Chrome, extension pinned, signed in to needed accounts, laptop charged
  • PIN written down (not shared)
  • Invigilator colleagues have dashboard logins
Test day

Run

  • −15 min: dashboard open (wakes the server), live view open
  • −5 min: PIN announced; watch Joined X / Y; help "Not joined"
  • Start: release the quiz
  • During: red tiles first; many flags on one site = add it with "Allow"
  • Extra time needed: Edit exam → Ends → Save
After (+15 min)

Review

  • Each flagged student: read flag + timeline + activity log together
  • Dismiss innocent flags, confirm the rest, each with a note
  • Export flags (CSV) and file it with the test records
  • Anything confirmed: integrity process, student gets to respond
Never

Don't

  • Edit or delete another colleague's test
  • Allow broad sites (google.com, office.com) or "whole site" for a Google Form
  • Treat a flag as proof on its own
  • Share student data beyond those who need it
Green tile: on an allowed site
Red tile: not allowed or another app, right now
Amber tile: offline 90 s+ (often Wi-Fi)
Grey tile: not joined yet
